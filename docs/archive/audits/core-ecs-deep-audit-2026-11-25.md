## C02 — Event callback sırasında aynı event kuyruğuna send, iterator/reference geçerliliğini bozabilir (P1, S)

Kanıt: [modules/world/include/astral/world/world.hpp:46–75](https://github.com/inkbytefo/AstralEngine/blob/d7260cab025677f9c98aee3792277f526e6ccf2f/modules/world/include/astral/world/world.hpp#L46-L75) Events::read current_ ve previous_ vector'lerini range-for ile gezer ve fn(item.value) çağırır. Aynı callback World::send<T> çağırırsa [modules/world/include/astral/world/world.hpp:438–446](https://github.com/inkbytefo/AstralEngine/blob/d7260cab025677f9c98aee3792277f526e6ccf2f/modules/world/include/astral/world/world.hpp#L438-L446) aynı current_ vector'ine push_back yapar. current_ iterasyonu sırasında reallocation tüm referansları/iterator'ları, reallocation olmasa bile eski end iterator'ü geçersiz kılar. Düzeltme: read başlangıcında sabit upper event id ve stabil snapshot/batch; reentrant send'leri sonraki batch'e ayır. Büyük event'lerde kopyasız immutable chunk/queue düşünülebilir. Cursor yalnız gerçekten gözden geçirilen aralığa ilerlesin. Callback çalışırken global mutex tutma.
Test: mevcut current/previous event okurken aynı türde event gönder; yeni event'i bir sonraki read'de tam bir kez al; büyüme, nested reader, callback exception ve aynı frame çoklu okuma. [modules/world/tests/query_test.cpp:121–144](https://github.com/inkbytefo/AstralEngine/blob/d7260cab025677f9c98aee3792277f526e6ccf2f/modules/world/tests/query_test.cpp#L121-L144) normal read/update senaryosu içeriyor, reentrant test değil.
