# AstralEngine M3 — Render Graph ve Hibrit Deferred Renderer

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans.

**Goal:** Render graph (otomatik bariyer, geçici texture havuzu, kullanılmayan pass ayıklama) ve onun
üzerinde hibrit deferred renderer: mesh G-buffer + SDF raymarch + PBR aydınlatma + yönlü gölge + tonemap.
Eski v2'deki teknikler temiz yeniden yazılır.

**Architecture:** `RenderGraph` render modülünde, public (ileri kullanıcılar kendi pass'lerini ekler).
Pass'ler okuduğu/yazdığı texture'ları bildirir; graph durum geçişlerini ve render pass başlangıcını
kendisi yapar. Renderer = sabit bir pass dizisi: Shadow → GBuffer(mesh) → SDF(compute) → Lighting(compute,
mesh/SDF derinlik kompoziti) → Tonemap(fullscreen → hedef). HDR ara texture'lar formatsız storage image.

**Spec:** ADR-0003, ADR-0008, roadmap M3.

## Review Focus
1. Pass sırası ve bariyerler: okunan texture önceki pass'in yazdığı durumdan doğru geçişle gelir.
2. Geçici texture'lar kareler arası güvenle yeniden kullanılır (GPU hâlâ okurken değil).
3. Hedef boyutu değişince tüm geçici kaynaklar yeniden oluşur.
4. SDF yokken / ışık yokken / mesh yokken boş sahne doğru render edilir.
5. Gölge haritası kamera hareketinde titremez/yanlış alanı kaplamaz (makul sınırlar).

## Tasks
1. gpu: formatsız storage image yazımı, derinlik texture'larının örneklenmesi (layout), `RGBA16Float`/`R32Float` storage.
2. render/graph: `RenderGraph`, `PassBuilder`, `PassContext`, culling, transient havuz; testler.
3. render/deferred: shader'lar + `Renderer` yeniden yazımı; `RenderScene` (mesh'ler, SDF şekilleri, nokta ışıklar, güneş, ortam); piksel testleri.
4. app: `SdfShape`, `PointLight` component'leri, `Material` alanları; örnek `sdf_scene`.
5. Dokümanlar + inceleme + push.
