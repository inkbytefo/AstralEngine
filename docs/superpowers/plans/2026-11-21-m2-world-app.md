# AstralEngine M2 — World (ECS) ve App Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans.

**Goal:** Kendi archetype ECS'imiz (`Astral::World`), oyunların yazıldığı `Astral::App` katmanı
(Game + System + Context), basit forward mesh renderer (`Astral::Render` çekirdeği) ve `spinning_cubes`.

**Architecture:** World yalnız Core'a bağlı (headless). Component'ler düz struct; tip kimliği derleme
zamanı hash'i (global sayaç yok). Archetype = aynı component kümesine sahip entity'lerin SoA sütunları.
Yapısal değişiklikler iterasyon sırasında `Commands` ile ertelenir. App: Window + Device + Swapchain +
JobSystem + World + Renderer'ı kurar; kare sırası Input → Update system'leri → transform yayılımı →
render. Headless App (pencere/GPU yok) testler için.

**Spec:** ADR-0005 (kendi ECS), ADR-0006 (App katmanı).

## Global Constraints
- World public API'de üçüncü parti tip yok; `std::` dışı bağımlılık yok.
- Component tipleri taşınabilir (move-constructible) olmalı; trivially copyable zorunlu değil.
- `each` sırasında yapısal değişiklik (add/remove/destroy) yasak → `Commands`.

## Review Focus
1. Entity silinip slot yeniden kullanılınca eski `Entity` geçersiz.
2. Component ekle/çıkar arşetip değiştirirken diğer component değerleri korunur (move), yıkıcılar bir kez çalışır.
3. `each` içinde `Commands` ile spawn/destroy: iterasyon bozulmaz, sonra uygulanır.
4. `parallel_each` her entity'yi tam bir kez işler.
5. Headless App N kare koşar, system sırası korunur.

## Tasks
1. **world/component:** `component_id<T>()` (constexpr FNV-1a), `ComponentInfo` (size, align, move, destroy).
2. **world/archetype + World:** `create/destroy/alive`, `add/remove/get/has`, archetype geçişleri, `each<A...>`, `count`.
3. **world/commands + parallel_each:** `Commands` (spawn/add/remove/destroy ertelenmiş), `apply`; `parallel_each` JobSystem ile.
4. **world/transform:** `Transform`, `Parent`, `WorldTransform`, `update_transforms(World&)` (hiyerarşi).
5. **render (çekirdek):** `Renderer`: `Mesh` (cube/plane primitifleri), `MeshRenderer` {mesh, color}, `Camera`, forward pass + derinlik + yönlü ışık, instance verisi GPU'ya buffer ile. Offscreen test: piksel kontrolü.
6. **app:** `App`, `AppDesc`, `Game`, `System`, `Context`, `Phase`; headless mod + `run_frames(n)`; testler.
7. **örnek:** `examples/spinning_cubes` (Game + Spin component + SpinSystem).
8. **Dokümanlar + inceleme + push.**
